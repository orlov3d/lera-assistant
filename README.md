# Lera Assistant — публичные страницы OAuth

Этот репозиторий существует ровно для одной цели: отдать Google три публичные ссылки,
без которых OAuth-приложение нельзя опубликовать.

- [Главная](https://orlov3d.github.io/lera-assistant/)
- [Политика конфиденциальности](https://orlov3d.github.io/lera-assistant/privacy.html)
- [Условия использования](https://orlov3d.github.io/lera-assistant/terms.html)

Здесь нет ни кода, ни документации, ни личных данных — только страницы для OAuth consent screen.
GitHub Pages на бесплатном тарифе работает только из публичных репозиториев, поэтому эти
три файла вынесены отдельно.

Документация и скрипты — в закрытом репозитории `hermes-deploy-packages`:

- `docs/OAuth_Notes.txt` — права, токены и 9 правил публикации OAuth-приложения
- `docs/Voice_and_Google_Setup.md` — полный цикл настройки с чистой машины
- `docs/scripts/` — распознавание, озвучка, авторизация, проверка токена
