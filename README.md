# Lera Assistant

Персональный цифровой ассистент, работающий локально на компьютере владельца.

- **[SETUP.md](SETUP.md)** — полный цикл настройки с нуля: распознавание речи, озвучка, доступ к Google, публикация OAuth-приложения и грабли, на которые мы уже наступили.
- Публичные страницы для Google OAuth: [главная](https://orlov3d.github.io/lera-assistant/), [политика конфиденциальности](https://orlov3d.github.io/lera-assistant/privacy.html), [условия использования](https://orlov3d.github.io/lera-assistant/terms.html).

## Что умеет

- принимает голосовые сообщения и расшифровывает их локально (faster-whisper, без интернета);
- отвечает голосом на голосовые;
- ведёт календарь, задачи, заметки и семейный бюджет через Google API;
- работает по расписанию: утренняя сводка, напоминания, проверка доступа.

## Быстрый старт

```bash
git clone https://github.com/orlov3d/lera-assistant.git

# откройте SETUP.md и идите по разделам по порядку
```
