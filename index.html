Lera Assistant

Личный цифровой ассистент

Lera Assistant — персональный помощник, работающий локально на компьютере владельца. Он помогает вести календарь, задачи, заметки и семейный бюджет, используя Google API (Gmail, Календарь, Диск, Таблицы, Задачи, Контакты) только для данных самого владельца.

Приложение не является публичным сервисом: оно не регистрирует новых пользователей, не предоставляет доступ третьим лицам и не используется в коммерческих целях.
